# ai-frontend-capstone
AI-powered frontend development capstone project built during the FlyRank Frontend AI Engineering internship.
## Goals

- Build a practical AI-powered frontend application.
- Practice AI-assisted development.
- Follow clean and accessible frontend development practices.
- Continuously improve the project throughout the FlyRank internship.

## Installation & Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/zainab-webdev8/ai-frontend-capstone.git
   cd ai-frontend-capstone
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:

   ```bash
   npm start
   # or
   yarn start
   ```

4. Open http://localhost:3000 in your browser.
