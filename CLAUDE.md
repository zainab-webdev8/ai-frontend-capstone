# Project Guidelines

## Project
AI-powered frontend development capstone for the FlyRank Frontend AI Engineering internship.

## Planned Stack
- React.js
- JavaScript
- HTML5
- CSS3
- Git and GitHub

## Coding Conventions
- Write clean and readable code.
- Use meaningful variable and function names.
- Keep components small and reusable.
- Follow responsive web design practices.
- Use semantic HTML.
- Consider accessibility in UI development.
- Do not add unnecessary dependencies.
- Test changes before committing.

## AI Development Rules
- AI may be used for brainstorming, coding, debugging, and reviewing.
- Review AI-generated code before accepting it.
- Keep the final implementation understandable and maintainable.
- Do not blindly accept AI suggestions.
